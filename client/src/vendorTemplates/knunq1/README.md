# Baptism Angel Invitation

React + Vite responsive baptism invitation built from the supplied assets.

## Run

```bash
npm install
npm run dev
```

## Edit invitation data

Open `src/App.jsx` and update the `CONFIG` object at the top:
- childName
- date/time
- church / reception names and addresses
- Google Maps links
- RSVP deadline

## Assets

- `src/assets/images/church.png`

- `src/assets/images/angel.png`
- `src/assets/images/cross.png`
- `src/assets/fonts/BubbleSans.otf`
- `src/assets/audio/baptism-music.mp3`

Browser autoplay policies may prevent sound from starting before the first user interaction. The fixed music button always provides play/pause control.
