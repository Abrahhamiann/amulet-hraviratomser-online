# Amulet Army Invitation

React + Vite online invitation template for an army send-off event.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Edit invitation information

Open `src/App.jsx` and change the `INVITATION` object near the top of the file.

## Included assets

- Custom Armenian font from the uploaded font archive
- Uploaded 3D army emblem
- Uploaded MP3 song used by the hero play/pause button

The RSVP form is front-end demo behavior only. Connect `submit()` in `src/App.jsx` to your Amulet API when integrating into production.
