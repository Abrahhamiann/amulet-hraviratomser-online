# Վերջին զանգի հրավեր — React + Vite

## Գործարկում

```bash
npm install
npm run dev
```

## Փոփոխվող տվյալներ

Հիմնական տեքստերը, ամսաթիվը, դասարանը, քարտեզների և Telegram-ի հղումները գտնվում են `src/App.jsx` ֆայլի սկզբում՝ `CONFIG` օբյեկտում։

Երաժշտությունը՝ `src/assets/verjin-zang.mp3`։ Browser-ը կարող է արգելել ձայնով autoplay-ը մինչև առաջին click/touch-ը. կոդը այդ դեպքում երգը միացնում է առաջին interaction-ի ժամանակ։ Վերևի աջ music button-ը Play/Pause է անում։

Font-ը՝ `src/assets/fonts/davel-aghvor.otf`։
