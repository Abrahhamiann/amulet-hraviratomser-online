# Engagement Burgundy Film Invitation

React + Vite responsive նշանադրության հրավեր։

## Run

```bash
npm install
npm run dev
```

## Edit main invitation data
Open `src/App.jsx` and change the `CONFIG` object: names, date, time, restaurant, address and map link.

## Assets
- `src/assets/images/heart.png` — chat-uploaded heart
- `src/assets/images/couple-1.jpg ... couple-5.jpg` — chat-uploaded couple photos
- `src/assets/fonts/BubbleSans.otf` — chat-uploaded Armenian font
