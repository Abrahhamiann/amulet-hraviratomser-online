# Amulet Army Invitation

React + Vite invitation design.

## Run

```bash
npm install
npm run dev
```

## Edit invitation data
Open `src/App.jsx` and change the `INVITATION` object.

## Assets
- `camouflage-bg.png` – supplied Armenian/camouflage invitation background
- `soldier-photo.jpg` – supplied portrait
- `invitation-song.mp3` – supplied music track
- `army-emblem.png` – army emblem used in the previous invitation direction
- `Arzumanian Aero Sans.ttf` – supplied font
