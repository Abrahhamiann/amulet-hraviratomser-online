# Wedding Love Roadmap Invitation

React + Vite հարսանյաց հրավեր՝ օգտագործելով տրամադրված asset-ները և font-երը։

## Գործարկում

```bash
npm install
npm run dev
```

## Տվյալների փոփոխում

`src/App.jsx` ֆայլի վերևում փոխեք `CONFIG` object-ը՝ անուններ, ամսաթիվ, վայրեր, ժամեր և Google Maps հղումներ։

## Fonts

- `src/assets/fonts/BlackWilliam.otf` — լատինատառ դեկորատիվ տեքստերի համար
- `src/assets/fonts/BubbleSans.otf` — հայկական տեքստերի համար
